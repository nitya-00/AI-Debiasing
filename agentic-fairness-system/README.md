# Agentic AI Fairness System

This repository contains a Spring Boot backend and Python agent services designed for bias detection, root cause analysis, mitigation strategy generation, validation, and monitoring in an AI fairness workflow.

## Structure

- `backend/`: Spring Boot API, Kafka integration, database access, and orchestration.
- `agents/`: Python-based fairness agents and shared utilities.
- `kubernetes/`: Deployment manifests for cloud-native deployment.
- `database/`: SQL migrations and initialization scripts.
- `docs/`: Architectural and setup documentation.
- `.github/workflows/`: CI/CD workflow definitions.
